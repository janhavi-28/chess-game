3. SOUND ARCHITECTURE: WHERE SOUNDS ARE STORED & HOW THEY WORK
--------------------------------------------------------------------------------

The sound system is structured across 3 distinct tiers:

TIER 1: SYNTHESIZED WOODEN BOARD SOUNDS (Zero External Files)
- Location in Code: Frontend/src/utils/soundEffects.ts (ChessSoundEngine)
- Technology: Native Web Audio API (AudioContext)
- How It Works:
  * Generates physical wooden board sound effects on the fly using oscillators and gain envelopes.
  * Piece Movement: playMove() triggers a triangle oscillator at 340Hz decaying to 110Hz in 65ms.
  * Piece Capture: playCapture() triggers a sine oscillator (480Hz -> 75Hz) and a triangle oscillator
    (240Hz -> 50Hz) producing a deep double wood knock.

TIER 2: PRE-RECORDED MP3 AUDIO FILES (Static Assets)
- Storage Location on Disk: Frontend/public/Chess_Project_Voices/
- Playback Mechanism: Loaded via new Audio('/Chess_Project_Voices/<file>.mp3') in coachVoice.ts.
- Audio File Inventory:
  1. "Good move.mp3"               -> Played on Good and Best moves.
  2. "Book.mp3"                    -> Played on Opening Book moves.
  3. "That's a slight inaccuracy.mp3" -> Played on Inaccuracy moves (CP loss 41-90).
  4. "Hold on, that's a mistake...mp3" -> Played on Mistake moves (CP loss 91-180).
  5. "That's a blunder..mp3"       -> Played on Blunder moves (CP loss 181-350).
  6. "That's a serious blunder..mp3" -> Played on Worst Moves (CP loss > 350).
  7. "Watch out! Here is their plan..mp3" -> Played when clicking "Show Follow Up Moves".
  8. "win.mp3"                     -> Played when checkmating the opponent.
  9. "move.mp3"                   -> Alternative move tap sound.

TIER 3: LIVE SPOKEN VOICE VIA WEB SPEECH API (TTS)
- Location in Code: Frontend/src/utils/soundEffects.ts (speakCoachMessage)
- Technology: window.speechSynthesis & SpeechSynthesisUtterance
- Voice Selection: Automatically prioritizes natural English male voices (David, Mark, Guy, Google US English).
- Subtitle Sync: Dispatches 'coach-subtitle' custom events to render text in SpeechBubble.tsx.
- Use Cases:
  * Dynamic Refutation Warnings: Analyzes engine refutation and speaks:
    "Watch out! You will lose your Queen if you make this move."
  * 18+ Savage Roast Mode: Delivers short, punchy, uncensored trash-talk lines from roastDialogues.ts.
  * Rating & Game Mode Announcements: "Club Player Mode, Rating 1500."

4. END-TO-END MOVE-TO-VOICE LOGIC PIPELINE (HOW BLUNDERS TRIGGER AUDIO)
--------------------------------------------------------------------------------

Here is the exact step-by-step lifecycle from piece drop to spoken voice:

1. Piece Dropped on Board:
   - User drags or clicks a move in ChessBoardArea.tsx.
   - Triggers handlePieceDrop() in ChessApp.tsx.

2. Pre-Check Request to Backend:
   - ChessApp.tsx sends POST /api/move/precheck with { game_id, move_uci }.
   - Backend evaluates centipawn loss and returns:
     { label: "Blunder", cp_loss: 240, refutation_sequence: ["e7e5", "d1h5", ...], threat_preview: "..." }

3. Board State & Overlay Activation:
   - ChessApp.tsx inspects the label:
     * If label is "Mistake", "Blunder", or "Worst Move":
       - Sets warningActive = true.
       - Highlights the blunder's destination square in SOLID RED (badMoveSquare).
       - Mounts the pre-commit CoachOverlay.tsx card over the board.

4. Voice Engine Decision Tree:
   - ChessApp.tsx checks audio settings:
     * Case A: Roast Mode is ACTIVE (roastModeActive === true):
       - Calls speakRoastPreMoveWarning() in coachVoice.ts.
       - coachVoice.ts requests an uncensored line from roastDialogues.ts via the non-repeating
         shuffle buffer (e.g., "What the fuck was that?", "Delete the fucking game, clown.").
       - speakCoachMessage() speaks the line live via window.speechSynthesis (Web Speech API).
       - Dispatches a 'coach-subtitle' event to render the text simultaneously in SpeechBubble.tsx.
     * Case B: Standard Coach Voice is ACTIVE (coachVoiceActive === true):
       - Calls speakMoveCategory("Blunder") in coachVoice.ts.
       - coachVoice.ts looks up AUDIO_FILES["Blunder"] -> "/Chess_Project_Voices/That's a blunder..mp3".
       - Plays the pre-recorded MP3 file at full volume via new Audio().
       - Dispatches "That's a blunder." subtitle to SpeechBubble.tsx.

5. "Show Follow Up Moves" Clicked:
   - If the user clicks 🛡️ "Show Follow Up Moves" on CoachOverlay.tsx:
     - The engine refutation moves animate on the board.
     - The opponent threatening piece is highlighted in blue.
     - speakDynamicRefutation() parses the captured pieces:
       * If user loses a Queen/Rook: speaks live via TTS "Watch out! You will lose your [Piece]..."
       * Fallback plays: "Watch out! Here is their plan..mp3".

5. HINT BOX LOCATION & BEHAVIOR
--------------------------------------------------------------------------------

- Where is it defined?
  Frontend/src/components/CoachOverlay.tsx (lines 53-65).
- When does it appear?
  Inside the floating pre-commit decision card whenever a player makes a bad move
  (Inaccuracy, Mistake, Blunder, or Worst Move, when warningActive === true).
- Button Rendering:
  <button onClick={onHintClick} className="...">💡 Hint Box</button>
- What happens when clicked:
  1. Calls onHintClick() passed from ChessApp.tsx.
  2. Sets showHint = true in ChessApp.tsx state.
  3. ChessBoardArea.tsx receives hintSquare (the starting square of Stockfish's #1 top move).
  4. Renders a prominent green square highlight on that piece, showing the learner which
     piece they ought to move instead.

--------------------------------------------------------------------------------

- Where is it defined?
  Frontend/src/components/BoardThemeSelector.tsx.
- Where is it rendered?
  Inside Frontend/src/components/ChessBoardArea.tsx (line 143).

  Anchored using absolute CSS classes: "absolute -left-12 bottom-0 z-20".

  of the 8x8 chessboard grid.
- Button Appearance:
  A circular theme button with a Lucide Palette icon (<Palette className="w-5 h-5" />).
- How it works:
  1. Clicking it opens a popup palette drawer with 5 custom color swatches:
     - Classic Wood (#d18b47 / #ffce9e)
     - Midnight Blue (#2c3e50 / #bdc3c7)
     - Emerald Green (#2e7d32 / #a5d6a7)
     - Coral (#c0392b / #f1948a)

  3. Automatically saves the selected theme string in the browser's localStorage
     ("smartchess_board_theme"), ensuring it persists across browser sessions.

7. PUZZLES ON THE FRONTEND (CLIENT-SIDE EXECUTION)
--------------------------------------------------------------------------------

- Handled in: Frontend/src/components/ChessApp.tsx.
- State Variables:
  * isPuzzleMode (boolean): Toggles board into puzzle solving layout.
  * puzzleData (object): Holds current puzzle ID, FEN, moves sequence, and rating.
  * puzzleMoveIndex (number): Tracks current turn within multi-move tactical combinations.
- API Client Integration (Frontend/src/services/api.ts):
  * api.startPuzzle(tier): Calls POST /api/puzzles/start to fetch a new tactical puzzle.
  * api.attemptPuzzleMove(puzzleId, moveUci): Calls POST /api/puzzles/attempt to verify move.
- Audio & UI Feedback:
  * speakPuzzleStartAnnouncement("White"/"Black"): Informs user which color to play.
  * Solved State: Plays victory sound (win.mp3) and displays congratulatory modal.
  * Failed Attempt: Alerts player that the move is incorrect, highlights square, and allows retry.
